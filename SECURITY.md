# Security

## Supported versions

This repository is a **benchmark and documentation harness**, not a shipped binary product. Security fixes apply to scripts and automation on the **default branch** (`main`). There are no separate release branches unless maintainers add them explicitly.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for undisclosed security vulnerabilities (especially anything involving live cluster credentials, tokens, or customer data).

Preferred options:

1. Use **[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/reporting-a-security-vulnerability)** for this repository if it is enabled by the org or owner.
2. Otherwise, contact the repository maintainers through your organization's standard security disclosure channel.

Include steps to reproduce, impact, and any suggested mitigation if you have one.

## Response

Maintainers will acknowledge receipt as capacity allows. This is a community-focused tooling repo; there is no formal SLA.
