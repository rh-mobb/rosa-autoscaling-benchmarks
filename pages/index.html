ROSA autoscaling benchmarks

This site hosts static demos from the GitHub repository: an illustrative browser simulator (no cluster required) and the Slidev deck comparing ROSA Classic with hosted control planes and AutoNode, grounded in timed benchmark runs.

Simulator

Toy model of traffic, HPA, CAS vs AutoNode-style delays, balloon slack, and cost framing. Open simulator/index.html locally or use this hosted copy.

Deck

Built Slidev presentation: methodology, timelines, economics, and recommendations from the benchmark harness.

Source and benchmark scripts live in the repo. For simulator architecture see simulator/README.md. Pages deploy from the main branch via GitHub Actions.
