  • State progression: waiting → pending → installing → ready — no unexpected state transitions.

Narrative

This run completed in 52m 49s — well within the expected 45–65 min range for ROSA Classic. The dominant phase was AWS infrastructure provisioning through OCM (51m 41s), which is normal for a multi-AZ classic cluster. Once the cluster reached ready state in OCM, post-ready steps were unusually fast: the API server was immediately reachable (oc login in 46s), all 3 default workers were already Ready (4s), and all ClusterOperators converged in under 20s. Compared to the previous run of this cluster on 2026-05-07 (163m 15s total), this run was 3× faster — the prior run's delay was in the manual_operator_roles_and_oidc phase (95m32s), which this run completed automatically in ~1 minute, suggesting the prior run had encountered a workflow issue. This run represents a clean baseline for the full benchmark suite.
