Narrative

The control plane and workers were provisioned quickly enough for OCM to report ready, but concurrent mutations (machine pools + identity provider) hit an OCM authorization error. This repository’s clusters/hcp/lib-terraform.sh supports a phased apply (ROSA_HCP_POST_CLUSTER_SLEEP_SEC, default 60s) to reduce transient 403s; confirm the run used a revision that enables it, and verify the RHCS_TOKEN / OCM role can modify the cluster resource. For a apples-to-apples install benchmark, retry make create-hcp after make destroy-hcp (or a fresh cluster name) once API access is stable; reconcile drift with terraform apply from clusters/hcp/terraform if state exists locally.
